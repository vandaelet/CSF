Coachfiches versleutelen

Met deze pagina maak je van de leesbare coachfiches (coach-bron.js, privé) het versleutelde bestand coachfiches.js voor de site. Alles gebeurt in je eigen browser: er wordt niets verstuurd.

  1. Kies het bestand coach-bron.js.
  2. Typ de coachcode twee keer. Wil je een nieuwe code? Typ dan gewoon de nieuwe.
  3. Klik op Versleutelen. Het bestand coachfiches.js wordt gedownload.
  4. Upload het op GitHub in de map coach/ en vervang het oude bestand.
